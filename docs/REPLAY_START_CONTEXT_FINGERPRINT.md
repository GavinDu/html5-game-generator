Its only accepted input mode is the strict canonical typed Game IR v1.0 minimal `game_start→add_score` subset with **empty** input-edge list and a bounded virtual horizon from 1 through 108,000 fixed 60Hz ticks. The Go caller supplies a seed and horizon; no CSPRNG/issuer/session ownership is claimed.

After `reduceStartScoreDiagnostic` admits and executes authored start actions, this helper deterministically hashes Go's typed JSON serialization of the admitted IR and binds that hash, the already-pinned ordered action trace SHA-256, a context version tag, the supplied seed, virtual duration, and resulting score into a new SHA-256. It rejects unsupported IR, any input edge (including blank edges), nil IR or an out-of-range horizon **without returning partial identity or score**. The transcript uses an explicit domain version plus ASCII hex digests and decimal integer fields, not ambiguous raw author-controlled JSON concatenation.
